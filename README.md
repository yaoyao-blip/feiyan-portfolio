# 钟飞燕 · 交互作品集

直接双击 `index.html` 即可打开，无需安装依赖。建议使用 Edge、Chrome 或 Safari 的较新版本。

## 页面

- 首页：保留封面原始标题字形，分层透明文件夹响应鼠标移动。点击后，五张原有彩色文件依次沿不同轨迹向右上方飞出，每次的间隔、速度和旋转角度略有变化，完成后进入目录。背景为白色点阵，浅蓝和薄荷绿光晕跟随鼠标，附近点阵轻微散开并回弹；静止后停止重绘，手机与减少动态效果模式保留静态背景。
- 关于：从首页向下滚动，展示教育背景、课程与经历。白色面板（含顶部圆角标签区）使用与首页相同的点阵和鼠标光晕，蓝色外框保持原样。右侧使用提供的真实照片；悬停时照片与联系卡从文件夹内展开，点击可固定展开，再次点击或按 Escape 收起。手机支持点按。联系卡保留指定感谢语，邮箱可点击调用邮件应用。
- 目录：保留原有文字与白色背景，8 个彩色文件夹采用单排倾斜立体书架排列。悬停抬起，点击后翻转打开，真实作品图片从文件夹内飞出，再进入详情；手机可横向滑动浏览。
- 详情：完整收录 PDF 第 4–44 页，可查看大图、用方向键切换图片、返回目录或前往下一个作品。

支持手机布局、键盘操作、浏览器前进后退和系统「减少动态效果」设置。手机在大图预览中点击图片可切换原尺寸横向查看。

## 本地预览

已安装 Node.js 时，在此目录运行：

```sh
node server.cjs
```

打开 http://localhost:4173 。也可以将本目录全部文件上传至任意静态网站托管服务。

## GitHub Pages

本网站由 HTML、CSS、JavaScript 和本地图片、视频组成，无需构建或后端服务。`server.cjs` 仅用于本地预览，线上无需运行。

发布源使用 `main` 分支根目录 `/`。根目录的 `.nojekyll` 禁用 Jekyll 处理，所有资源采用相对路径，作品页使用 hash 路由，因此兼容 `https://用户名.github.io/仓库名/#project/animation` 形式的地址。后续更新文件并推送到 `main` 即可触发重新发布。

## 文件与修改

- `index.html`：网站入口。
- `styles.css`：基础排版、响应式与动效。
- `shelf.css`：目录书架布局、文件夹翻转与作品飞出动画。
- `profile.css`：个人照片、联系卡与文件夹展开动效。
- `hero-scatter.css`：首页文件依次向右上飞出的转场。
- `ambient.css` / `ambient.js`：首页白色点阵、清新光晕与鼠标交互。
- `app.js`：作品资料、路由、分层文件夹与交互。
- `assets/`：从原 PDF 渲染的 WebP 图片和封面字形裁切素材。

原稿页面保留原有视觉与文字。网页中的介绍文字根据原作品内容整理；海派流光栏目已在项目扉页后接入用户提供的完整影片（约 3 分 3 秒），带原生播放、进度和全屏控制；动画栏目已在项目扉页后接入《怒放色彩篇》完整影片（30 秒），同时保留 PDF 中已有的封面、流程和分镜。提供的屏幕录制仅作为交互动效参考，不作为作品内容展示。

本地服务器支持视频流式传输与 Range 请求，便于拖动进度；影片文件为 `assets/haipai-liuguang.mp4` 和 `assets/molly-blooming-colors.mp4`。
